Dokumentasi Project CuffnCode Web

Simulasi Web Monitoring Tekanan Darah Digital Berbasis Logic Code

1. Deskripsi Project

CuffnCode Web adalah mini project berbasis web yang mensimulasikan sistem pengukuran tekanan darah digital. Project ini tidak menggunakan hardware asli secara langsung, tetapi memvisualisasikan alur kerja sensor tekanan, penguatan sinyal, pembacaan ADC, dan pengolahan data melalui logic code JavaScript.

2. Tujuan Project

  • Memahami konsep sistem monitoring tekanan darah digital.
  • Membuat implementasi logic code berbasis web.
  • Menampilkan data tekanan darah secara realtime melalui dashboard.
  • Mendokumentasikan project melalui GitHub Pages.

3. Komponen Referensi

Komponen Fungsi
MPS20N0040D Sensor tekanan untuk membaca tekanan udara dari manset.
AD620 Instrumentation amplifier untuk memperkuat sinyal kecil dari sensor.
TLC2272 Op-amp untuk membantu pengondisian sinyal dan offset.
ADC / Mikrokontroler Mengubah sinyal analog menjadi data digital.
Web Logic Code Menghitung tekanan darah, MAP, BPM, dan klasifikasi status.

4. Alur Sistem

  1. Sensor membaca tekanan dari manset.
  2. Sinyal sensor diperkuat oleh AD620.
  3. Sinyal dikondisikan menggunakan TLC2272.
  4. Nilai analog dikonversi menjadi nilai ADC.
  5. Program web memproses data ADC menjadi tekanan dalam mmHg.
  6. Dashboard menampilkan sistolik, diastolik, MAP, BPM, status, dan grafik sinyal.

5. Logic Code Utama

Program menggunakan beberapa fungsi utama:

  • convertAdcToVoltage(): mengubah nilai ADC menjadi tegangan.
  • convertVoltageToPressure(): mengubah tegangan menjadi estimasi tekanan.
  • calculateMAP(): menghitung Mean Arterial Pressure.
  • classifyPressure(): menentukan status tekanan darah.
  • simulateSensorSignal(): membuat simulasi sinyal tekanan realtime.

6. Output Web

Output yang ditampilkan berupa dashboard realtime yang menampilkan nilai sistolik, diastolik, MAP, BPM, nilai ADC, tekanan sensor, grafik sinyal, dan log pengukuran.

7. Cara Menjalankan

  1. Ekstrak folder project.
  2. Buka file index.html di browser.
  3. Klik tombol Mulai untuk menjalankan simulasi.
  4. Gunakan menu mode pasien untuk mengubah skenario pengukuran.
